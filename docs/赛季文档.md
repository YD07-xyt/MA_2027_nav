总体的思路是 以机器人为中心构建一个局部滑动的3d occ map 并实时通过terrain 分析去除坡度，限高杆，地面等障碍物并降为成2d 珊格地图 并构建esdf
其中我们设计了建图，导航2种模式 
建图模式下会保留2d map的障碍物信息，并结合局部地图的射线衰减提高实际的建图质量，不至于动态障碍物拖影，鬼影建入地图
导航模式下会加载一张先验地图，并开启时间衰减3d occ map 用于解决动态障碍物拖影问题(由于射线衰减会由于雷达视野问题导致无法快速衰减动态障碍物)
1.3d occ map
核心思想：采用 ROG-Map 的概率体素地图。每个体素存占据的对数几率，射线终点命中加分、射线穿过减分；只维护以车为中心的固定大小局部块，车移动时环形缓冲平移。
建模：体素x 的对数几率 L(x)，L(x) = logit(p(x)) = ln( p(x) / (1 - p(x)) )
$$L \leftarrow \operatorname{clamp}\!\big(L + n_{hit}\,l_{hit} \text{ 或 } n_{miss}\,l_{miss},\ l_{min},\ l_{max}\big),\quad
l_{\ast}=\operatorname{logit}(p_{\ast})$$

2.terrain 地形分析
我们以3d occ map为输入，过滤坡、悬空杆，地面 
核心思想：以地面层为参考地面，分两类判据：
- 地面判据：只看地面本身的形状，判出台阶上沿和陡坡；
- 体素判据：看地面以上的占据体素，判出墙、立柱和净空不足的悬空物。
我们希望依赖一个地面做为过滤的参考，由于比赛的地图是固定的，可以提前确定导航的地面
所以一个自然的方法就是以初始化的位置构建一个地面，并以此为参考，但是这个实现并不灵活，一是不利于我们进行调试，2是在高地上参考的实际地面应该是高地的地面，尽管通过固定的高度可以过滤，但是我们追求更灵活鲁棒的实现
由此我们将3d occ map 的每个列内最低占据体素，并做中值滤波 形成一个临时地面 作为参考
这样可以摆脱固定的参考地面，但是由于导航模式下使用了时间衰减，以及雷达视野的局限，导致实际3d occ map 的地面点稀疏导致判断错误的问题，由此我们引入了一个持久 2.5D 地面层，并较好的解决了这个问题
持久 2.5D 地面层
核心思想：单独维护一张跨帧持久的 2.5D 地面高度图 G(k)，k 为 2D 格。它直接用原始点云更新，不随 3D 体素被擦除而消失。更新遵循"易降难升"：地面估计只会被更低的一致观测拉低，被更高的观测抬高需要更多证据，高出太多的视为悬空物。
结合实际的比赛工况，我们可以判断若某列最低占据的正下方已证实为空、且空闲段一直通到邻域地面，这一列是悬空结构的下沿
由此的参考地面：每格取地面层高度 G。地面层缺失时，取列内最低占据体素，并做中值滤波。
陡坡判据：逐格对 5×5 邻域的地面拟合平面  z=ax+by+c：
$$\text{steep}\iff \sqrt{a^2+b^2}>\tan\theta_{max}\ \land\ \text{RMS}<e_{max}$$
只有拟合残差小、确实是坡面时才按坡度判；杂乱物体的残差大，交给其他判据。
体素判据：对每格，在参考地面以上取最低的占据体素 z_low，将实际下方有空闲的悬浮障碍物过滤掉

$$\text{gap}=z_{low}-G,\qquad
\begin{cases}

\text{gap}\ge h_{robot} & \Rightarrow \text{可从下方通过}\\
h_{min}\le\text{gap}<h_{robot}\ \land\ \text{下方已证实为空} & \Rightarrow \text{可从下方通过}\\
\text{其他} & \Rightarrow \text{障碍}
\end{cases}$$
4.2d esdf 构建
核心思想：对 2D 占据栅格做精确欧氏距离变换，得到有符号距离 d(p)：自由区为正，障碍内部为负。距离变换采用按行、按列分离的一维下包络算法，复杂度与格数成线性。

$$d(\mathbf{p})=
\begin{cases}
\ \ \min_{\mathbf{q}\in O}\|\mathbf{p}-\mathbf{q}\|, & \mathbf{p}\notin O\\
-\min_{\mathbf{q}\notin O}\|\mathbf{p}-\mathbf{q}\|, & \mathbf{p}\in O
\end{cases}$$
梯度增强(参考中科大的方案):查询时以最近格心为中心，在 3×3 邻域上做二次插值，梯度 ∇d∇d 由插值权重解析求导得到，保证梯度连续；贴近地图边界时退回双线性插值。
