# 接口契约

触发：新增公开接口，或改变跨模块数据、状态、错误、所有权、时间或性能条件。

## 确认内容

给出拟放入当前模块 `include/` 的类型/方法草案及调用方影响，回答适用项：

| 项目 | 必须明确 |
| :--- | :--- |
| 输入 | 合法范围、单位、坐标系、由谁校验 |
| 时间 | 时钟域、事件时间/接收时间、外部传入与离线回放语义 |
| 所有权 | 借用/持有、读写者、指针与视图失效时机 |
| 状态 | 构造/init/set_param/reset 的等价性、调用顺序、历史状态 |
| 结果/失败 | 返回值含义、失败是否保留旧路径/样条、部分输出是否有效 |
| 并发 | 允许的同时调用、同步责任、快照一致性 |
| 性能 | 受约束阶段、最大容量、超限策略、测量方式 |
| 兼容 | 影响的调用方、参数、ROS 协议及有意行为变化 |

完成条件：调用方可据此正确使用；影响实现的未决选择已确认。稳定契约写在公开声明旁，跨模块关系写架构索引。

## 设计与验收

- 优先具体类和值语义，抽象对应真实变化需求。
- 多阶段结果优先成功后整体提交；继续旧轨迹或部分提交属于业务选择，需确认。
- 借用优先 const 引用/span，共享只读快照考虑 shared_ptr<const T>；具体变更须核对当前调用方。
- 按变化验证正常、边界、失败后状态、重复初始化/reset、快照/借用、并发及容量场景。编译通过只证明编译范围。
